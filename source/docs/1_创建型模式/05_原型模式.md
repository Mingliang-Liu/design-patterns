# 05 原型模式（Prototype Pattern） 

LML一句话总结：  
**构造函数成本高？我直接copy一份你的的对象再调教**  
通过复制现有对象（原型）来创建新对象，而不是通过类来实例化。这种方式特别适合当创建对象的成本较高，或者需要创建多个相似对象时使用。  

## 传统新建对象的问题
```
import time

class UserProfile:
    def __init__(self, user_id):
        self.user_id = user_id
        self.basic_info = self._load_from_db()
        self.preferences = self._load_from_file()
        self.tags = self._compute_tags()

    def _load_from_db(self):
        print("Loading from database...")
        time.sleep(1)  # 模拟IO
        return {"name": "Alice", "age": 25}

    def _load_from_file(self):
        print("Reading from file...")
        time.sleep(1)
        return {"theme": "dark", "language": "en"}

    def _compute_tags(self):
        print("Computing tags...")
        time.sleep(1)
        return ["active", "premium"]
```
同一个用户，每次都重新加载 = 浪费资源
```
# 每次创建都要3秒 😅
user1 = UserProfile(1)
user2 = UserProfile(1)
```
## 原型模式
```
import copy

class UserProfile:
    def __init__(self, user_id):
        self.user_id = user_id
        self.basic_info = self._load_from_db()
        self.preferences = self._load_from_file()
        self.tags = self._compute_tags()

    def _load_from_db(self):
        print("Loading from database...")
        time.sleep(1)
        return {"name": "Alice", "age": 25}

    def _load_from_file(self):
        print("Reading from file...")
        time.sleep(1)
        return {"theme": "dark", "language": "en"}

    def _compute_tags(self):
        print("Computing tags...")
        time.sleep(1)
        return ["active", "premium"]

    def clone(self):
        return copy.deepcopy(self)
```

原型模式 =
**“用一次昂贵初始化 + 多次廉价复制，换取整体性能提升”**
